# DIA 홈페이지 제작용 Claude Design 마스터 프롬프트

아래 내용 전체를 하나의 프로젝트 지시문으로 이해하고, 설명용 기획안만 제시하지 말고 실제로 실행 가능한 반응형 홈페이지를 완성해 주세요.

---

## 1. 역할과 프로젝트 목표

당신은 B2B 헬스케어·글로벌 마케팅 분야의 시니어 브랜드 디자이너이자 UX 라이터, 프런트엔드 개발자입니다.

한국의 병원·브랜드 성장 기업 **DIA(디아)**의 공식 홈페이지를 제작합니다. 방문자가 첫 화면부터 아래 세 가지를 즉시 이해하고 신뢰할 수 있어야 합니다.

1. DIA는 단순 광고대행사가 아니라 **병원 현장 운영 경험을 기반으로 성장 구조를 설계하고 실행하는 회사**다.
2. DIA는 국내 병원 마케팅 전문성과 함께, **MEDIAT(중화권 해외환자 유치)**와 **DIAT(중화권 방한 고객 유치)**라는 두 개의 확장 서비스를 운영한다.
3. 콘텐츠 노출에서 끝나지 않고 **문의·상담·예약·방문·결제·재방문까지 연결되는 고객 여정**을 설계한다.

웹사이트의 최종 목적은 ‘신뢰 확보 → 서비스 이해 → 상담 문의 전환’입니다.

## 2. 참고 홈페이지 활용 원칙

정보 구조 참고: https://golddoctors.co.kr/

레퍼런스에서 참고할 것은 다음의 설득 흐름입니다.

- 첫 화면에서 고객의 문제와 회사의 해결 가치를 강하게 제시
- 수치나 현장 경험으로 신뢰 확보
- 함께한 업체 로고를 빠르게 노출
- 서비스 목록보다 성공을 만드는 구조를 먼저 설명
- 일반 대행사와의 차이를 명확히 비교
- 페이지 중간과 하단에 상담 CTA 반복

단, 레퍼런스의 문구, 이미지, 레드·블랙 컬러, 레이아웃을 그대로 복제하지 마세요. DIA만의 모던하고 미니멀한 디자인으로 재해석합니다. 과도하게 공격적인 광고대행사 분위기, 자극적인 매출 보장 표현, 확인되지 않은 업계 1위·성과 수치는 사용하지 않습니다.

## 3. 브랜드 구조와 정의

### DIA | Parent Brand

- 성격: 병원 현장 경험을 기반으로 국내 성장과 중화권 확장을 연결하는 Growth Operating Company
- 한 줄 정의: **현장에서 검증한 성장 전략으로, 한국의 병원과 브랜드를 중화권 고객에게 연결합니다.**
- 핵심 역량: 병원 운영 이해, 의료광고 실무, 네이버 매체 운영, 중화권 콘텐츠 현지화, 해외고객 상담·예약 여정 설계
- 핵심 태도: 현장 중심, 실행 중심, 투명한 데이터, 법규 준수, 장기적 성장

### MEDIAT | Greater China Medical Growth

- 한글 표기: **MEDIAT | 중화권 해외환자 유치**
- 대상: 피부과·성형외과·치과·한방병원·종합병원 등 국내 의료기관
- 역할: 중화권 잠재환자의 발견부터 상담, 예약, 내원, 사후관리까지 연결
- 핵심 서비스: 샤오홍슈 퍼스널 브랜딩, 중국어 숏폼 콘텐츠, 채널 운영, 다국어 상담 운영, 예약·내원 여정 설계, AI 기반 상담 CRM의 단계적 구축
- 핵심 문장: **조회수를 환자로, 문의를 실제 내원으로 연결합니다.**

### DIAT | Greater China Visit & Commerce Growth

- 한글 표기: **DIAT | 중화권 방한 고객 유치**
- 대상: 국내 F&B, 카페, 뷰티, 웰니스, 관광, 리테일 브랜드
- 역할: 한국을 방문하거나 한국 브랜드에 관심 있는 중화권 고객을 매장 방문과 구매로 연결
- 핵심 서비스: 중국 소비자 인사이트, 샤오홍슈·숏폼 콘텐츠, 브랜드/대표 퍼스널 브랜딩, 방한 동선 기반 매장 유입, 인플루언서·UGC 캠페인, 문의·예약 전환 설계
- 핵심 문장: **중국 고객이 한국에서 찾고, 저장하고, 직접 방문하게 만듭니다.**

### 방문자가 혼동하지 않게 표현할 것

- DIA는 회사이자 모브랜드입니다.
- MEDIAT와 DIAT는 DIA가 운영하는 두 개의 전문 서비스입니다.
- 국내 병원 마케팅은 DIA가 현장에서 축적한 기반 역량이며, MEDIAT의 신뢰 근거이기도 합니다.
- 세 개를 서로 경쟁하는 별도 회사처럼 보이게 만들지 마세요.

## 4. 제공 자산과 이미지 사용 지시

프로젝트에 업로드된 파일을 아래와 같이 사용하세요.

- `DIA_logo_purple_dot_transparent(1).png`: 헤더와 푸터의 DIA 로고. 투명 배경을 유지하고 비율을 왜곡하지 말 것.
- `MEDIAT 로고.png`: MEDIAT 서비스 섹션의 대표 로고. 원본에 넓은 흰 여백이 있으므로 필요하면 CSS `object-fit: contain`과 wrapper crop 방식으로 시각적 크기를 맞추되 원본을 찌그러뜨리지 말 것.
- `2b2811f8-dd3e-4137-947d-fb327f17560c.png`: “국내 매출의 한계와 해외환자 유치 필요”라는 문제의 참고 자료. 원본의 자극적인 광고 디자인을 메인 비주얼로 그대로 쓰지 말고, 핵심 메시지를 DIA 디자인 언어의 카드·인용문·간결한 도식으로 재구성할 것.
- `9d01e2c1-506d-48a0-89be-1c41ae32d2ce.png`: “여러 채널 문의, 번역, 자동응대가 분산된 문제”를 보여주는 현장 문제 참고 이미지. MEDIAT 문제 섹션에서 기기 목업 또는 작은 증거 이미지로 활용 가능.
- `a06c352f-66d3-4feb-846e-de3df435739b.png`: “문의부터 재방문까지 이어지는 통합 관리”의 기능 흐름 참고 이미지. MEDIAT 해결책 섹션의 보조 자료로 활용.

DIAT 전용 로고 파일은 아직 없으므로, 새 심벌을 임의로 만들지 말고 **DIA 로고와 어울리는 텍스트 워드마크 `DIAT`**를 임시로 사용하세요. 나중에 로고 파일 하나만 교체할 수 있도록 컴포넌트를 분리하세요.

파트너 병원 로고 파일이 아직 없다면 임의의 가짜 로고를 만들지 말고, 흰색 또는 옅은 회색의 동일 크기 카드에 병원명을 텍스트로 표시하세요. 추후 PNG/SVG 파일을 경로만 바꿔 교체할 수 있게 배열 데이터로 관리하세요.

## 5. 전체 디자인 방향

### 인상

- 의료 분야의 신뢰감 + 테크 기업의 정교함 + 중국 시장으로 확장되는 역동성
- 세련되고 미니멀하며 여백이 충분한 B2B 디자인
- ‘중국풍 장식’이나 붉은색·금색·용·전통 문양 등 진부한 이미지는 금지
- 흔한 병원 홈페이지처럼 의사 사진과 청진기 스톡 이미지를 남발하지 말 것
- 가벼운 마케팅 에이전시가 아니라 실제 운영을 이해하는 전문 파트너로 보이게 할 것

### 컬러 시스템

- 전체 배경: 오프화이트 `#F7F7F5`, 화이트 `#FFFFFF`, 일부 딥 네이비 `#081426`
- DIA 메인: 로고의 바이올렛 계열 `#6653D9` 중심
- MEDIAT 포인트: 딥 블루 `#0B3B75`, 브라이트 블루 `#1577FF`, 시안 `#10C5D6`
- DIAT 포인트: DIA 바이올렛을 기본으로 하되 코랄 `#FF725E` 또는 웜 오렌지를 작은 강조색으로만 사용
- 본문: 거의 검정에 가까운 `#121722`, 보조 텍스트 `#667085`
- 한 화면에서 포인트 컬러를 과하게 혼합하지 말고, 서비스별 섹션 안에서만 구분할 것

### 타이포그래피

- 한글: Pretendard 또는 SUIT
- 영문: Inter 또는 Manrope
- 큰 제목은 굵고 간결하게, 본문은 가독성 우선
- 데스크톱 H1은 56~72px, 모바일 H1은 36~44px 범위에서 반응형 적용
- 자극적인 붓글씨, 과도한 그라데이션 텍스트, 너무 둥근 키즈풍 폰트는 사용하지 말 것

### 그래픽 모티프

- DIA 로고의 보라색 점과 MEDIAT 로고의 파도·연결 곡선을 활용
- ‘한국 ↔ 중화권’을 직접적인 국기 아이콘보다 흐르는 선, 좌표점, 연결되는 여정으로 표현
- 얇은 라인, 반투명 글래스 카드, 은은한 그리드와 블러를 제한적으로 사용
- 스크롤 애니메이션은 짧고 부드럽게. 화려한 3D나 과도한 패럴랙스는 금지

`FROM LOCAL EXPERTISE TO GREATER CHINA GROWTH`

**현장에서 검증한 성장 전략으로,

CTA:

- Primary: `우리 브랜드 성장 구조 진단받기`
- Secondary: `MEDIAT · DIAT 살펴보기`

Hero 우측 또는 하단에는 아래 세 요소가 연결되는 정교한 비주얼을 배치하세요.

- `DIA | 현장 기반 성장 전략`
- `MEDIAT | 해외환자 유치`
- `DIAT | 방한 고객 유치`

단순한 세 개 카드 나열보다 DIA에서 두 서비스로 자연스럽게 확장되는 브랜드 관계가 보이도록 구성합니다. CTA 클릭 시 각각 문의 폼 또는 서비스 섹션으로 스크롤합니다.

### SECTION 2. 함께한 파트너 로고 마키

제목:

**현장을 함께 이해하고, 성장을 함께 만들어갑니다.**

로고/명칭 목록:

1. 신청춘한방병원
2. 그레이스병원
3. 오늘의 치과
4. 한마음병원
5. 청담솔루션의원

모션 사양:

- 로고들이 화면 **오른쪽에서 왼쪽으로** 끊김 없이 이동
- 동일 트랙을 두 번 복제해 빈 공간 없는 seamless marquee 구현
- 데스크톱 약 24~30초, 모바일 약 18~22초의 부드러운 linear infinite animation
- 기본은 grayscale 및 65~75% opacity, hover 시 원색과 100% opacity
- 로고 카드 높이와 시각적 크기를 통일하되 원본 비율은 유지
- hover 또는 focus 시 애니메이션을 잠시 멈출 수 있게 구현
- `prefers-reduced-motion` 사용자는 애니메이션 없이 가로 스크롤 또는 정적 그리드로 표시
- 로고마다 alt text를 정확히 입력

이 섹션은 Hero 바로 아래에 두어 사회적 증거를 빠르게 제공합니다.

## 8. 인터랙션과 반응형 상세 사양

- 모든 섹션은 desktop, tablet, mobile에서 완전히 반응형이어야 함
- 모바일에서 2~3열 카드는 1열로 전환
- Hero CTA는 모바일에서 세로 배치하거나 충분한 터치 영역 확보
- 내비게이션은 모바일 햄버거 메뉴로 전환하고 열림/닫힘 상태와 키보드 접근성 구현
- 앵커 이동 시 sticky header에 콘텐츠가 가려지지 않도록 `scroll-margin-top` 적용
- 스크롤 진입 애니메이션은 opacity + translate 16~24px 수준으로 절제
- Partner logo marquee 외에는 무한 애니메이션을 남발하지 말 것
- CTA, 탭, 카드에는 hover뿐 아니라 focus-visible 상태 구현
- 색 대비 WCAG AA 수준을 지향
- 이미지에 의미 있는 alt text 제공, 장식 이미지는 빈 alt 처리
- `prefers-reduced-motion` 지원
- CLS를 줄이도록 이미지 width/height 또는 aspect-ratio 지정

## 9. 개발 및 파일 구조 요구사항

가능하면 **React + TypeScript + Vite + Tailwind CSS**로 구현하세요. 기존 프로젝트가 있다면 기존 스택과 구조를 우선 유지합니다.

구현 원칙:

- 설명 문서만 작성하지 말고 실제 동작하는 페이지 완성
- 섹션별 컴포넌트 분리
- 파트너 로고, 서비스, 프로세스, 사례는 배열 데이터로 관리
- 불필요한 대형 라이브러리는 추가하지 말 것
- 애니메이션 라이브러리가 기존에 없다면 CSS 중심으로 구현
- 모든 버튼의 목적지가 실제 anchor 또는 명시적 placeholder여야 함
- 브라우저 콘솔 에러 0개
- 모바일 가로 스크롤 오류 0개
- 이미지 파일명에 공백이나 한글이 있어 import가 깨질 경우 안전한 영문 파일명으로 복사하고 참조 경로를 정리
- SEO title: `DIA | 국내 병원 마케팅·중화권 고객 유치`
- Meta description: `병원 현장에서 시작한 DIA가 국내 병원 마케팅부터 MEDIAT 해외환자 유치, DIAT 중화권 방한 고객 유치까지 설계하고 실행합니다.`
- Open Graph 기본 메타태그 작성
- 구조화 데이터는 실제 회사 정보가 확정되지 않았다면 허위 정보 없이 최소화

README에 아래 교체 방법을 짧게 정리하세요.

1. 파트너 로고 파일 교체 위치
2. 사례와 실제 성과 수치 입력 위치
3. 회사 정보 입력 위치
4. 문의 폼 endpoint 또는 카카오 링크 연결 위치
5. DIAT 정식 로고 교체 위치

## 10. 신뢰와 법적 표현 원칙

- 확인되지 않은 `1위`, `유일`, `무조건`, `매출 보장`, `환자 수 보장` 사용 금지
- 가짜 수치, 가짜 후기, 가짜 병원장 추천사 생성 금지
- 의료광고 관련 서비스는 법률 자문처럼 단정하지 않고 `심의 지원`, `기준 검토`, `표현 리스크 관리`로 표현
- 해외환자 유치 관련 자격·등록 여부가 확인되지 않았다면 등록 완료로 단정하지 말 것
- AI CRM은 현재 구축/도입 단계가 구분되도록 표현
- 협력사 로고는 실제 사용 권한과 최종 파일을 전달받은 후 게시한다는 전제로 placeholder 제공
